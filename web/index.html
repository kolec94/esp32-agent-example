Requires a Chromium-based browser (Chrome, Edge, Opera) with Web Serial support. Firmware is rebuilt automatically from the source repo when a sketch changes. Flash-usage percentages come from the actual compiled binary size for the partition scheme assumed in scripts/build-firmware.sh - if your board uses a different flash size/partition table, sizes may not reflect it exactly.
